
# 01 - Business Understanding

## 1. Context

Banks receive numerous loan applications and need to evaluate the risk associated with each applicant.

## 2. Business Problem

How can historical loan application data be used to predict whether a new loan application is likely to be approved?

## 3. Project Objectives

- Understand the banking problem.
- Identify relevant applicant characteristics.
- Build a classification model.
- Evaluate its performance.
- Develop a web application.

## 4. Machine Learning Task

This is a supervised binary classification problem.

Target variable: Loan_Status

- Y: Approved
- N: Rejected

## 5. Expected Outcome

A predictive model that estimates the loan approval status based on applicant information.
